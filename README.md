# 🧸 Tienda E-commerce: Happy Kids

Este repositorio contiene el prototipo frontend de una tienda de juguetes.

## 🚀 Enlace al Proyecto
**[👉 Haz clic aquí para ver el proyecto en vivo y navegable](https://sebasepulvedarios.github.io/Desarrollo-Web-y-M-vil/Proyecto%20Frontend/index.html)**

## 🛠️ Características Principales
* **Catálogo Dinámico:** Filtrado de productos en tiempo real por precio.
* **Carrito de Compras:** Sistema funcional de suma, resta y eliminación de productos.
* **Diseño Responsivo:** Adaptable a dispositivos móviles y escritorio.
